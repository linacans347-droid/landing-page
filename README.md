# Product Landing Page 🎯

Современный, адаптивный одностраничный сайт (лендинг) для презентации продукта. Проект создан в рамках практического освоения семантической вёрстки и адаптивного веб-дизайна.

## 🚀 Демонстрация
[Посмотреть проект в действии](https://github.io)

## 🛠 Технологический стек
* **HTML5** — семантическая структура страницы (`header`, `section`, `footer`), использование форм и валидация ввода данных.
* **CSS3** — позиционирование элементов, построение гибких сеток (Flexbox), кастомные медиа-запросы (`@media`) для создания отзывчивого дизайна.

## 💡 Реализованный функционал
* **Адаптивная вёрстка:** Лендинг одинаково красиво отображается на смартфонах, планшетах и широкоформатных мониторах.
* **Интерактивные элементы:** Фиксированная навигационная панель для удобного скролла и работающая форма подписки на email.
* **Медиа-контент:** Встроенный видеоплеер, адаптированный под размеры контейнера.

## 🔧 Как запустить проект локально
1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com
   ```
2. Откройте файл `index.html` в вашем браузере.
